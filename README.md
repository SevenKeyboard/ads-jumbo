# adsjumbo
Banner advertisement host/embedding helper for AutoHotkey GUIs.

To use this library, you also need a separately built executable from **[banner-ad-host-adsjumbo](https://github.com/SevenKeyboard/banner-ad-host-adsjumbo/tree/main)**.
